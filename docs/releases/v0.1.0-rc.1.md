# ChessLab PC v0.1.0-rc.1 — UAT Windows

Rilis percobaan Windows x64 dengan setup terisolasi, build berlisensi, dan
perbaikan pemantauan setelah aktivasi. Target endpoint desktop pada rilis UAT ini
adalah **http://localhost:8080**, yaitu server lokal pada PC yang menjalankan EXE.

## Perubahan

- Bootstrap CPython 3.13 x64 dan dependency Windows terkunci.
- Inisialisasi konfigurasi tanpa menimpa preferensi yang sudah ada.
- Validasi Stockfish 19, seluruh kelas PNG, public key Ed25519 dan input bebas rahasia.
- Build EXE menjalankan audit arsip, uji startup serta pemindahan folder.
- Aktivasi pertama melanjutkan autostart; Jeda manual tetap dihormati.
- Diagnosis dan petunjuk pembelajaran tema jika papan belum dikenali.
- Image API lisensi dan dashboard tersedia melalui GitHub Container Registry.

## Memakai EXE

1. Unduh ZIP Windows dan cocokkan SHA-256 dengan `SHA256SUMS.txt`.
2. Ekstrak ke folder yang bisa ditulis, lalu buka `ChessLab-Coach.exe`.
3. Jalankan stack lisensi UAT lokal dan gunakan lisensi khusus QA dari administrator.
4. Untuk tema papan baru, pilih orientasi eksplisit, sesuaikan FEN, lalu gunakan
   **Deteksi & pelajari (3 dtk)** sebelum memulai pemantauan.

Pembaruan EXE mempertahankan `ChessLab-data` dan cache aktivasi perangkat.
Paket hanya menyertakan konfigurasi lisensi publik; private key, `.env`, database
dan kredensial administrator tidak disertakan.

## Cakupan pengujian

Workflow tag menjalankan tes Windows dengan engine nyata, audit EXE, smoke/relokasi,
serta build kedua image sebelum menerbitkan rilis. Hasil lokal sebelum otomasi rilis
ditambahkan: 192 tes lulus. Pengujian alur rekomendasi memakai grant QA bertanda tangan
dengan transport test, tanpa mengubah record lisensi server.

Aktivasi/lifecycle online menggunakan lisensi QA nyata dan matriks PC Windows 10
masih memerlukan UAT manual. Rilis ini adalah **prerelease**, bukan deployment produksi.
